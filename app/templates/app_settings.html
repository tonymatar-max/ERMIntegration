OpenRouter (AI)

Connect an OpenRouter API key and pick a model to power the app's AI features. The key is stored encrypted, the same way the Redmine key is.

Create one at openrouter.ai → Keys. Leave blank to keep the current key.

One model per line (or comma-separated), up to 3 (OpenRouter's limit). The first is primary; if it's down, rate-limited or refuses, OpenRouter falls back to the next. Browse ids at openrouter.ai/models. Text/chat models only.

Email (SMTP)

Outgoing email so the app can send alerts and the weekly digest. The password is stored encrypted. For Office 365 use smtp.office365.com port 587 (TLS); for Gmail, an app password.
